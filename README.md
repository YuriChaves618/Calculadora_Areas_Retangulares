
 # 📐 Calculadora de Áreas Retangulares

> Uma aplicação simples, prática e eficiente para cálculo de área de figuras e superfícies retangulares.

---

##  Sobre o Projeto

A **Calculadora de Áreas Retangulares** foi desenvolvida para facilitar o cálculo rápido e preciso da área ($A = b \times h$)  de formas retangulares.

É uma ferramenta ideal para estudos de geometria, lógica de programação ou para uso prático em estimativas de terrenos, cômodos, pisos e reformas.

---

##  Funcionalidades

-  **Cálculo da Área:** Multiplicação da base (largura) pela altura (comprimento).
-  **Validação de Dados:** Prevenção contra a entrada de valores nulos ou negativos.
-  **Interface Direta:** Resposta rápida e formatada para o usuário.
